\# 📊 Retail Sales Analysis using SQL



\## Project Overview



This project analyzes the sales performance of the ClassicModels company using SQL.



The goal is to answer real business questions related to:



\- Sales Performance

\- Customer Analysis

\- Product Performance

\- Employee Performance

\- Office Performance



The project demonstrates SQL skills commonly required for Data Analyst roles.



\---



\## Business Problem



ClassicModels wants to understand its business performance and identify opportunities to improve revenue, customer satisfaction, and sales efficiency.



The analysis focuses on finding actionable business insights from historical sales data.



\---
